# Dogs JavaScript API Slideshow

**Name:** Fernando Montiel  
**License:** MIT  

---

**Project Description**

This project is a simple web application that displays images of dog breeds using a public API.
It was created to practice JavaScript Fetch, Promises, Async/Await, JSON, and AJAX, and to deploy
a working application using Azure Website hosting.
